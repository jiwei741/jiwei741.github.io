# 背景图放这里

把你自己的图片**直接拖进这个文件夹**就行。支持 `jpg` / `jpeg` / `png` / `webp` / `avif`。

## 行为

- 放 **1 张** → 每次访问都用这张
- 放 **多张** → 每次访问**随机**挑一张（刷新页面可能就变了）
- 这个目录**为空** → 不显示背景图，网站回到纯色背景

## 注意

- 建议宽度 **1920px 以上**，风景／纹理／抽象图比人像更适合当背景
- 图片会在构建时被自动压缩转码，所以**原始文件大一点没关系**
- 文件名用英文／数字最省事，避免空格

## 调整浓淡和模糊

打开 `src/styles/background.css`，改最上面两个变量：

```css
--bg-opacity: 0.15;   /* 越大图越明显 */
--bg-blur: 0px;       /* 柔焦程度 */
```

## 删除背景

把图片从这里删掉即可，**不需要改任何代码**。
